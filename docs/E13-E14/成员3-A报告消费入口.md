新增 `mode=e13-b`。CLI：`python3 run_e11e12.py run --request <请求> --out work/<新目录>`。异步 API 仍使用 `POST /v1/jobs` 的 `input` 和 `idempotency_key`；客户端轮询 B 任务并按产物清单取文件。此模式处理离线放入 `data/` 的文件，API 不代为下载任意外部 URL。
