# ADR E11 E12 仓库和输入版本

日期：2026-11-10。负责人：241880492。

保留已有 GitHub 实验主仓库及两条旧检查，增量导入教师 E11/E12，避免丢失本组去重和路径保护。TinyExpr 独立 fork 保留来源及许可证，默认分支不改；课程分支在上游 C0 增加实际 Docker 输入和独立行为检查，再 merge 上游 C1，保留源变更归属。此方案形成有实际变更的可比较版本，不伪造日期或缺失依赖。

本次检测限定 `make example`，附加 smoke 与依赖图范围分开。原 source Makefile 保持缺失依赖，自动修复应发生在独立工作副本；手工探针仅作预检。正式 runner、候选镜像和跨组接口仍需负责人适配。固定样例继续作为原链路基线。

GitLab 另建阶段备份分支，不改写旧 A/B 分支。接口与云主机实测、课程选题认可不由仓库创建或 CI 成功代替。
