# 成员 1 DRAFT 设计说明

本人负责候选与运行环境。候选保留上游项目 COPY、构建和 CMD 指令，以实际程序输出验收。基础镜像固定摘要，两轮使用同一基底，区分缺少 make 和基础设施下载失败。按 image_id 禁网运行并保存 inspect，避免标签变化影响验收。

检测与修复阶段应挂载各阶段实际源码副本，设置对应工作目录并使用 DRAFT 镜像。本人用目标副本验证工具链及行为；成员 3 将该约定接入正式编排。基础镜像摘要跨平台，具体 image_id 和运行证据按执行平台分别保存。

公共阶段、接口和任务关联采用成员 3 的 ADR。本人承担候选来源、镜像构建和独立运行部分，编排身份及 API 持久化由成员 3 实现。[公共 ADR](../../241880546/e11-e12/ADR.md)
