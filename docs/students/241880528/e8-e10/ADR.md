# ADR：隐式规则采用动态依赖跟踪

状态：在当前受控样例中采用并验证。

决定：保留模式规则，采用DeepSeek首轮候选，
使用编译器生成.d并由Make加载，不逐个硬编码头文件。
显式基线仅处理MISSING，不自动删除REDUNDANT。

依据：MDfixer论文§III-E、Fig.9的隐式规则LLM修复路径。
候选在独立副本验证，原始回复和基线保持不变。

代价：依赖GCC兼容的选项，增加.d文件管理；
未覆盖所有Make语法、配置变化或依赖文件单独丢失场景。

验证：构建、默认目标、头文件触发、无关对象保持、
clean build产物一致、新增include跟踪、依赖重检与clean清理。
