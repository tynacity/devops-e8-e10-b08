# ADR：DRAFT实际环境复用与隔离API验收

状态：已实现并通过课程云主机固定样例、API与SSH转发验收（2026-11-10）。

## 问题

原参考编排器在DRAFT构建完成后继续用编排容器的工具运行检测和验证，不能证明下游实际复用DRAFT环境。成员1固定样例候选仅安装编译工具，缺少后续Git和strace。共享默认API状态目录也会使多次验收互相影响。

## 决策

由`DraftRuntime`在每次DRAFT构建返回的实际镜像ID内执行下游操作，并挂载本轮工作副本。宿主入口显式传递`E11_HOST_ROOT`，解决嵌套Docker中的宿主路径映射。保留每条运行命令、退出码、原始输出与阶段结果。E11-A独立模式继续使用已有检测环境。

新增个人固定样例候选，仅通过RUN安装Git/strace并配置镜像源，保持原项目、COPY、构建及运行指令。它具有自己的候选哈希，原交接样例的Git提交不变。

API支持指定work下的独立状态目录及明确容器名，用于重启自己的服务。新增个人测试覆盖真实HTTP幂等/冲突、产物哈希与越界拒绝、未完成产物、状态恢复，以及实际工作副本到宿主Docker挂载的映射。

状态与JSON产物使用同目录临时文件加原子替换，降低服务被中断时留下半份state.json而无法恢复的风险。

## 验证与边界

本机通过6项个人测试及13项原有可移植测试。课程Linux主机在源码提交`12c3c99c0027c189a8ff4d5ff307052469e40b8b`上通过完整24项测试和22项E8–E10回归；固定样例CLI/API五阶段、实际DRAFT镜像复用、四类报告拒绝、真实重启恢复和本机SSH转发均已通过。原始归档542个文件通过哈希校验。

CLI与API为两次独立DRAFT运行，各自镜像ID及job_id/trace_id保留；同一任务的全部下游操作复用该任务的实际镜像。SSH客户端通过幂等键复用原API任务，没有再次调度构建。

证据与完整版本见[固定样例与API验收](固定样例与API验收.md)。正式A组输入和TinyExpr完整编排尚待A组材料，当前固定样例结果不能替代该验收。
